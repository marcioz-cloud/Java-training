Este repositório contém meus projetos de estudo e prática na linguagem Java. 

Ele é composto por três pequenos programas que exploram conceitos fundamentais de programação e interface gráfica. 
Abaixo estão os detalhes de cada um dos projetos:

Projetos
1. Jogo Gênio

Este programa é um jogo simples onde o "gênio" gera um número aleatório, e o jogador deve adivinhar qual é esse número.
O número aleatório é gerado utilizando a funcionalidade Math.random() da biblioteca Math, que fornece ferramentas matemáticas úteis no Java.
O programa realiza comparações lógicas entre o número inserido pelo usuário e o número gerado pelo sistema, retornando mensagens que indicam se o jogador acertou ou errou.

Técnicas utilizadas:
Biblioteca Math para geração de números aleatórios.
Lógica de controle de fluxo (if/else) para verificar a resposta do usuário.
Interação com o usuário via console.

2. Para Meu Amor
Um conjunto de programas interativos que utilizam janelas gráficas para criar uma experiência divertida e personalizada.
O programa utiliza a biblioteca Swing, especificamente a classe JFrame, para criar janelas de perguntas e respostas.
As respostas são validadas por meio de condições lógicas, garantindo a interação adequada entre o usuário e o sistema.

Técnicas utilizadas:
Swing para construção de interfaces gráficas.
Manipulação de eventos para tratar ações do usuário, como cliques em botões.
Validação de respostas para garantir a consistência das interações.

3. Primeiro Programa
Este é o meu primeiro programa em Java, criado para exibir mensagens simples no console.

Biblioteca Math: usada no Jogo Gênio para operações matemáticas e geração de números aleatórios.
Biblioteca Swing: usada no Para Meu Amor para criação de janelas e interfaces gráficas interativas.
